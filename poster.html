ALL EYES ON INDEPENDENTS

Remotion · React · 1080 × 1350 · 60 fps

WHAT IT IS

A vertical event poster that animates by words. Every word of both text blocks flies in from off-canvas, lands with a little overshoot, holds, then leaves to the left — faster on the way out than on the way in. Two and a half seconds, on a loop.

HOW IT'S BUILT

The frame is a React component. Remotion renders that component once per frame and encodes the result to H.264 — so the timing lives in code, not in a timeline, and the whole thing is diffable and re-renderable from a single command. Source is in motion/ in this repo; npm run render produces the file playing above.

  • Intro — each word starts three canvas widths off the right edge and takes 1s to land, with a 100 ms forward stagger. The stagger is spaced linearly; the overshoot is on each word's own travel.
  • Hold — the last word settles at 1.4s, and the finished composition sits still until 1.64s.
  • Exit — 500 ms per word, 50 ms stagger, two canvas widths to the left, on an ease that leans back a touch before accelerating away. Last word clears at 2.34s.

THE PART THAT NEEDED TUNING

An overshoot ease is a percentage of the distance travelled, and the distance here is three canvas widths — so a textbook easeOutBack threw each word 317 px past its mark and slammed it into the neighbouring word. The curve in src/easing.ts is tuned to peak 18 px past the resting position instead: still a springy landing, but smaller than the gap between words, so the type never collides mid-cascade.
